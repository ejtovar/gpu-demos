# GPU fluid demos

Two finite element solvers from [ryujin](https://github.com/conservation-laws/ryujin), ported to WebGPU and running entirely on the device's GPU:

- **Runoff**: ryujin's shallow water scheme, flash floods driven by rain.
- **Supersonic**: ryujin's Euler equations (ideal gas), a Mach 3 stream past a cylinder you can drag.

Open **https://ejtovar.github.io/gpu-demos/** on a phone and add an app to the home screen (iPhone: Share → Add to Home Screen; Android: menu → Install app). Needs WebGPU: Safari 26+ on iPhone/iPad, Chrome or Edge on Android and desktop.

`docs/` is the published site. It is generated by `node tools/deploy.mjs`, which builds both apps from their (private) source repositories next to this one and adds the web-app manifest, icons, and an offline service worker. `node tools/icons.mjs` redraws the icons.
